# Group19-Payment.Processing.System
Distributed Payment Processing System for an e-commerce platform supporting concurrent transactions. Maintains consistency during node failures and network delays while synchronizing payment history across servers. Uses Stripe/PayPal sandbox and demonstrates fault tolerance, recovery mechanisms, and high availability in distributed environments.

Initial Spring Boot setup for distributed system prototype.

## Features (to be implemented)
- Fault Tolerance
- Replication
- Time Synchronization
- Consensus

## Run
mvn spring-boot:run
